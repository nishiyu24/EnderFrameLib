A browser engine inside Minecraft

One document model. Every screen.

Layout
Block, Flexbox, Grid & Tables

Real CSS layout with margin collapsing, wrapping, named grid areas, colspan and multi-column text.

Headless state
No server DOM. Deltas only.

The server keeps a small key/value state and flushes only what changed at the end of each tick.

Reactive
Bindings without scripts

data-bind, {{key}}, data-if and data-for keep the markup in sync with state.

Rendering
SDF shaders & FBO layers

Rounded corners, soft shadows, gradients, blur and blend modes, drawn on the GPU.

Live data
PubSub channels

Publish once and every subscribed HUD or screen updates in real time.

Minecraft elements
Slots, energy, fluids, entities and item icons as tags

<mc-slot>, <mc-energy>, <mc-tank>, <mc-entity> and item: image URIs sit in your layout like any other element.

Workflow

From browser preview to in-game screen

Design with instant feedback, then bind state and ship.

1
Preview

Run /enderframe devkit and open the playground in any browser. No restart needed.

2
Write

Drop HTML and CSS into enderframe_ui/ in your assets or datapack.

3
Bind

Create a UIState on the server, or open a client session and edit the DOM directly.

4
Inspect

Press F12 for the DOM inspector and F5 to hot-reload markup and styles.

FAQ

Good to know

Does it embed Chromium or run JavaScript?

No to both. The parser, CSS engine, layout and renderer are pure Java. Behavior comes from reactive attributes (data-bind, data-if, data-for), server UIState actions, or Java listeners on the client.

Can I design without launching Minecraft?

Yes. /enderframe devkit exports a browser playground with the engine's real user-agent stylesheet and themes. Open it in Chrome, Edge or Firefox.

Is it safe against malicious clients?

Every packet is checked: session ownership, viewer verification, per-player rate limits, NBT path filtering, and an allowlist of the action names your document declared.

How do I add it to my mod?

Add com.nishiyu.enderframelib:enderframelib:1.0.3 to your dependencies and declare it in neoforge.mods.toml. It needs Minecraft 1.21.1, NeoForge 21.1.248+ and Java 21.
