How-To & In-Game Documentation

EnderFrameLib へようこそ

EnderFrameLib は、Minecraft 1.21.1 (NeoForge) 内で本格的な HTML5 / CSS3 / Markdown による UI をネイティブレンダリングする次世代フレームワークです。

✨ 主な特徴

• 完全ゼロ依存: 外部ブラウザ（Chromium / CEF）を使用せず、純粋な Java 実装で数MBの超軽量・高速動作。

• Web標準準拠: Flexbox、Grid、角丸、影、アニメーション、グラデーション対応。

• リアクティブ同期: データパックやサーバー側 NBT 変更に即座に反応する宣言的 DOM バインディング。

クイックショートカット

• ESC: 画面を閉じる

• F12: DevTools インスペクタ（ボックスモデル・スタイルのリアルタイム調査）

• F5: UI ホットリロード（HTML/CSS 変更の即時反映）

デスクトップ & ウィンドウ操作

Linux 風デスクトップ環境では、直感的なマルチウィンドウ操作が可能です。

🪟 ウィンドウ操作

• ドラッグ移動: ウィンドウ上部のタイトルバーを左クリックしたままドラッグすると、画面内を自由に配置できます。

• 画面端スナップ: ドラッグ中にカーソルを画面の左端・右端に当てると半分の幅に、上端（トップパネル）に当てると最大化します。離す前に青い枠で配置先を表示します。

• 引き出して復元: 最大化・スナップ中のウィンドウはタイトルバーを掴んで引き出すと、元の大きさに戻ってカーソルに付いてきます。

• 最大化 / 復元: タイトルバーをダブルクリック、または右上の □ ボタンをクリックすると全画面最大化 / 元のサイズ復元を切り替えられます。

• 最小化: 右上の − ボタンをクリックすると最小化され、ドックに収納されます。

• 閉じる: 右上の ✕ ボタンでウィンドウを閉じます。

• 最前面切り替え: ウィンドウの任意の場所をクリックすると自動的に最前面へ移動します。

⚓ ボトムドック (Dock)

画面下のアイコンをクリックすると、対応するアプリの表示 / 最小化を即座にトグルできます。起動中のアプリには下部にインジケータードットが表示されます。

bash ターミナル & コマンド

ターミナル（Terminal）ウィンドウでは、対話型のコマンドライン操作が可能です。

Web 開発仕様 & データパック UI

データパックを追加するだけで、誰でも簡単に独自のゲーム内 Web UI を作成できます。

📁 データパックの配置場所 data/<namespace>/enderframe_ui/<name>.html
⚡ 宣言的バインディング構文

• data-bind="text:my_val,style.color:my_color": 状態をテキストやCSSにバインド

• data-model="input_key": 入力欄の値を双方向バインド

• data-show="is_visible": 条件に応じた要素の表示/非表示

• onclick="action_name": クリック時に Java 側の onWebAction へ通知

🛠️ ブラウザ開発キット (DevKit)

/enderframe devkit を実行すると、通常の Chrome / Firefox でレイアウトを確認できる HTML プレビューキットがゲームディレクトリに出力されます。
