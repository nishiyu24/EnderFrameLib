2. インラインMinecraftアイテム＆タスクリストの検証

Markdownの標準画像構文 ![alt](item:...) を記述するだけで、MinecraftのアイテムとJEI/REIツールチップがインライン描画されます：

  • ダイヤモンド (item:minecraft:diamond) のインライン描画とJEI連携
  • ネザライトインゴット (item:minecraft:netherite_ingot) の表示
  • 金のリンゴ (item:minecraft:golden_apple) の表示
  • SVG・Canvas 2D の置換要素 (R8)
Tip

GUI画面で F12 キーを押すと 簡易インスペクタ が開き、ポインタの下の要素のタグ・id・class・矩形・バインディング属性を確認できます。F5 キーで文書の再読み込み、Tab キーまたは矢印キーでフォーカス移動が可能です。
